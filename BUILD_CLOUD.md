# Cloud build quick start

This repository includes `.github/workflows/build-windows.yml`.

- Create a private GitHub repository.
- Upload the project contents (including the hidden `.github` folder) to the repository root.
- Open Actions → Build HUMKT Auto Buyer for Windows → Run workflow.
- Download the generated artifact from the completed run.

No local Node.js, SDK, compiler, or .NET installation is needed on the target Windows PC.
